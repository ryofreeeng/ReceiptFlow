# ReceiptFlow 手順書

## 環境情報
- 言語：Python
- 認証：Google Drive API（OAuth2.0）
- OCR：EasyOCR（ローカル実行）
- 仕分け：Gemini API
- Excel出力：openpyxl

---

## Step 1：環境構築

### 1-1. ライブラリのインストール

```bash
cd /Users/hama/devWithClaude/ReceiptFlow
pip install -r requirements.txt
```

### 1-2. .envファイルの作成

`.env.example` をコピーして `.env` を作成し、実際のフォルダIDを記入する。

```bash
cp .env.example .env
```

`.env` の中身：
```
UNPROCESSED_FOLDER_ID=（DriveのunprocessedフォルダのURLの末尾IDを貼り付ける）
```

フォルダIDはDriveでフォルダを開いたときのURLの末尾：
```
https://drive.google.com/drive/folders/★ここ★
```

### 1-3. フォルダ構成の確認

```
ReceiptFlow/
├── receipts/
│   ├── unprocessed/   ← Adobe ScanのPDFを置く場所
│   └── processed/     ← 処理済みに移動される場所
├── output/            ← Excel出力先
├── credentials.json   ← Google Cloud Consoleからダウンロード済み（gitに上げない）
├── .env               ← フォルダIDなどの個人設定（gitに上げない）
├── .env.example       ← .envのテンプレート（gitに上げる）
├── requirements.txt
├── test_drive_connection.py  ← DriveからPDFをダウンロードする
├── ocr.py                    ← PDFからテキストを抽出する
└── docs/
    ├── 手順書.md（このファイル）
    ├── test_drive_connection_guide.md
    └── ocr_guide.md
```

## Step 2：Google Drive API 接続テスト

### 2-1. テストスクリプトの実行

```bash
python test_drive_connection.py
```

### 2-2. 初回実行時の流れ

1. ターミナルに `Google Drive APIに接続中...` と表示される
2. ブラウザが自動で開く
3. Googleアカウントでログインして「許可」をクリック
4. ブラウザに「認証完了」と表示されたら閉じる
5. ターミナルにDriveのファイル一覧が表示されれば成功

**成功時の出力例：**
```
Google Drive APIに接続中...

接続成功！ファイル一覧（最大10件）:
  マイドライブ  (application/vnd.google-apps.folder)
  ...
```

### 2-3. 2回目以降の実行

`token.json` が自動生成されているため、ブラウザは開かずにそのまま接続される。

## Step 3：OCR（PDFからテキスト抽出）

### 3-1. 前提条件

- `receipts/unprocessed/` にPDFが1件以上ある状態にする
  - 手動でフォルダにコピーするか、`python test_drive_connection.py` でDriveからダウンロードする

### 3-2. スクリプトの実行

```bash
python ocr.py
```

### 3-3. 初回実行時の注意

初回はEasyOCRが日本語・英語の認識モデルをダウンロードするため、**数分かかる**。

```
EasyOCRを初期化中...
```

と表示されたまましばらく待つ。2回目以降はダウンロード済みのモデルを使うため速い。

### 3-4. 成功時の出力例

```
EasyOCRを初期化中...

2件のPDFを処理します...

処理中: receipt_20250526.pdf
  1ページを画像に変換しました
  ページ 1 をOCR中...

--- receipt_20250526.pdf の抽出テキスト ---
〇〇スーパー
2025年05月26日
お茶        108円
弁当        540円
合計        648円
----------------------------------------
```

### 3-5. OCR精度が低い場合

`ocr.py` の `ZOOM` 定数を大きくすると精度が上がる（処理は遅くなる）：

```python
ZOOM = 2.0  # デフォルト。精度が足りなければ 3.0 に変える
```
