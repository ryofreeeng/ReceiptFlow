# ReceiptFlow 手順書

## 環境情報
- 言語：Python
- 認証：Google Drive API（OAuth2.0）
- OCR：EasyOCR（ローカル実行）
- 仕分け：Gemini API
- Excel出力：openpyxl

---

## Step 1：環境構築

### 1-1. ライブラリのインストール

```bash
cd /Users/hama/devWithClaude/ReceiptFlow
pip install -r requirements.txt
```

### 1-2. .envファイルの作成

`.env.example` をコピーして `.env` を作成し、実際のフォルダIDを記入する。

```bash
cp .env.example .env
```

`.env` の中身：
```
UNPROCESSED_FOLDER_ID=（DriveのunprocessedフォルダのURLの末尾IDを貼り付ける）
```

フォルダIDはDriveでフォルダを開いたときのURLの末尾：
```
https://drive.google.com/drive/folders/★ここ★
```

### 1-3. フォルダ構成の確認

```
ReceiptFlow/
├── receipts/
│   ├── unprocessed/   ← Adobe ScanのPDFを置く場所
│   └── processed/     ← 処理済みに移動される場所
├── output/            ← Excel出力先
├── credentials.json   ← Google Cloud Consoleからダウンロード済み（gitに上げない）
├── .env               ← フォルダIDなどの個人設定（gitに上げない）
├── .env.example       ← .envのテンプレート（gitに上げる）
├── requirements.txt
├── test_drive_connection.py
└── docs/
    └── 手順書.md（このファイル）
```

---

## Step 2：Google Drive API 接続テスト

### 2-1. テストスクリプトの実行

```bash
python test_drive_connection.py
```

### 2-2. 初回実行時の流れ

1. ターミナルに `Google Drive APIに接続中...` と表示される
2. ブラウザが自動で開く
3. Googleアカウントでログインして「許可」をクリック
4. ブラウザに「認証完了」と表示されたら閉じる
5. ターミナルにDriveのファイル一覧が表示されれば成功

**成功時の出力例：**
```
Google Drive APIに接続中...

接続成功！ファイル一覧（最大10件）:
  マイドライブ  (application/vnd.google-apps.folder)
  ...
```

### 2-3. 2回目以降の実行

`token.json` が自動生成されているため、ブラウザは開かずにそのまま接続される。
